# Google Material Symbols

The homepage playback controls embed Google's outlined 24px SVG paths:
`motion_play`, `motion_photos_paused`, `music_note`, `music_off`,
`dark_mode`, and `light_mode`.

Source: https://github.com/google/material-design-icons/tree/master/symbols/web
Licensed under Apache 2.0; see LICENSE. Paths are unchanged; presentation uses
currentColor and CSS state switching. SVG is embedded to avoid icon-font loading delays.
