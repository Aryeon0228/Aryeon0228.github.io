AI콘텐츠시스템설계 · 학생용 복사 프롬프트
PPT 페이지 순서

영어는 코딩 AI에 입력할 요청문, 한글은 같은 내용의 뜻.
[대괄호]를 자기 조건으로 바꾸고, 실제 프로젝트와 참고 자료를 함께 전달하기.
전체 목표 프롬프트와 단계별 실행 요청을 구분하기. 생성 결과는 브라우저에서 직접 확인하기.

04쪽 · 참고 관찰 정리
==================================================
영어 · 복사해서 입력
Analyze the attached reference for my miniature-island scene. Separate directly observable facts from implementation guesses. Describe the composition, visible input cues, state changes, motion direction, distance, duration, and feedback only where the material supports them. Label estimated values as estimates. If you cannot read the attachment or the link, say so and work from accessible images or my observation notes instead. Do not invent unseen content, source code, or measured fps. End with one interaction that a beginner could implement and verify locally.

한글 · 같은 요청의 뜻
첨부한 참고 자료를 미니어처 섬 장면 제작 관점에서 분석해줘. 직접 확인할 수 있는 사실과 구현에 관한 추정을 나눠줘. 자료에서 확인 가능한 화면 구성, 입력 단서, 상태 변화, 움직임의 방향·거리·시간, 피드백을 정리하고 추정값은 추정이라고 표시해줘. 첨부 파일이나 링크를 읽지 못하면 먼저 알려주고, 접근 가능한 이미지나 내가 적은 관찰 메모로 전환해줘. 보지 못한 내용이나 실제 코드, 측정하지 않은 fps를 지어내지 마. 마지막에는 초보자가 로컬에서 구현하고 확인할 수 있는 인터랙션 하나를 제안해줘.

10쪽 · 기본 장면 먼저 실행
==================================================
영어 · 복사해서 입력
Treat the prompt above as the final project vision. First inspect the provided island-3d-starter project and give its actual local run instructions. Preserve its compatible React 19 and @react-three/fiber v9 setup and existing working files. Check the procedurally generated island, beach, rocks, and water block. Keep MeshTransmissionMaterial and the preset from drei Environment. Do not arbitrarily load model files. Separate successful Environment preset loading from any fallback lighting. Defer GPU water simulation, jelly deformation, and postprocessing in this step. Describe the screen I should see and list implemented and unimplemented features separately. Do not claim that the full original prompt is complete.

한글 · 같은 요청의 뜻
위 요청문은 최종 목표로 유지해줘. 먼저 제공한 island-3d-starter 프로젝트를 확인하고 실제 로컬 실행 방법을 알려줘. 호환되는 React 19·R3F v9 구성과 실행되는 기존 파일을 보존해줘. 코드로 만든 섬·해변·바위·물 블록을 확인하고 MeshTransmissionMaterial과 drei Environment 프리셋을 유지해줘. 모델 파일은 임의로 불러오지 마. Environment 프리셋 로딩 성공과 대체 조명 사용은 구분해줘. 이번 단계의 GPU 수면·젤리 변형·후처리는 보류해줘. 확인할 화면과 구현·미구현 기능을 나눠 설명하고 원문의 전체 기능을 완료했다고 말하지 마.

13쪽 · 내 섬의 색 선택 기능 수정
==================================================
영어 · 복사해서 입력
Customize the water-color selection in the provided starter for my island. Replace the three color-preset buttons with [Shallow Sea, Deep Sea, Sunset] and use [my three chosen color values]. 한글 · 같은 요청의 뜻
제공된 시작 예제의 물 색 선택을 내 섬에 맞게 수정해줘. 색 선택 항목 3개를 [얕은 바다·깊은 바다·해질녘]으로 바꾸고 [내가 정한 색 3개]를 사용해줘. 버튼과 Leva가 하나의 색 값을 공유해 같은 3D 물 재질을 조절하고, 실제 화면에 즉시 반영되게 해줘. 버튼은 키보드로 선택할 수 있게 하고 현재 선택을 분명히 표시해줘. 지형·카메라·배경·조명·관계없는 동작은 유지하고 미구현 효과의 조절 항목은 추가하지 마. 입력 → 값 변경 → 재질 변화의 흐름과 관련 코드를 설명해줘. 버튼 변경, Leva 색 변경, 실제 물빛 확인 순서로 점검표를 알려줘.
