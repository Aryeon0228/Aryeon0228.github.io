시작 전 준비
  • 작업 폴더와 AI 코딩 도구 준비. 3D 프로젝트의 설치·실행 환경은 수업 전에 확인하기.
  • 제공된 HTML 도구는 다운로드한 파일을 브라우저에서 열어 사용하기.
  • 3D 소스 수정은 학생 ZIP의 island-3d-starter 폴더에서 진행. 먼저읽기.txt의 설치·실행 순서 확인하기.
  • 설치가 막히면 3D 시연 예제로 조절을 관찰하고 수정 명세 작성. 코드 수정 미실행은 따로 표시하기.
  • 환경 조명 프리셋은 외부 HDR을 읽음. 실패 시 기본 조명으로 이어지며 물 표현이 달라질 수 있음.
  • 참고 이미지는 프롬프트 도구에서 골라도 코딩 AI에 직접 첨부하기.
  • 자동 복사가 막히면 전체 문장을 선택해 Ctrl+C 또는 ⌘C로 복사하기.
  • 새로고침 전에 필요한 선택과 요청문을 한영 TXT로 저장하기.

오늘의 목표

  • 보이는 사실과 추정한 구현 방법 구분하기
  • 코드로 만든 섬·해변·물 블록을 브라우저에서 실행하기

기본과 심화

기본
시작 프로젝트를 실행하고 색 선택 항목의 이름과 값을 내 섬에 맞게 변경. Leva와 같은 물 색을 바꾸는지 확인하고 수정 전후 기록.
심화
기울기·젤리·GPU 수면·화면 효과 중 하나 선택. 실제 구현한 범위와 남은 기능을 구분하고 전후의 표현과 성능 비교.

함께 제출할 내용

  1. 실행 파일과 안내

    AI콘텐츠는 프로젝트와 실행 방법, 바이브코딩은 원본·수정본 HTML. 필요한 파일과 사용 버전, 완료·미구현 구분.

  2. 요청과 변경 기록

    선택 조건, 실제 사용한 프롬프트, 바꾼 부분과 유지 조건, A/B 화면과 최종 선택 이유.

  3. 검증과 자기 설명

    직접 해본 조작, 기기와 화면 조건, 확인·미확인 항목, 입력이 화면 변화로 이어지는 흐름.

  4. 출처와 남은 문제

    분석용 참고와 결과물에 포함한 자산의 출처·이용 조건을 구분. 해결하지 못한 문제 한 가지 기록.
